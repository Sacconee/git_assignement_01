# git_assignement_01



Working Tree:

la directory sul pc fisico dove si fanno le modifiche in locale prima che vengano pushate.

Staging Area:

zona in cui si decide quali modifiche saranno incluse nel prossimo commit.

Repository:

dopo aver eseguito un commit i dati citati nella staging area, passano da un salvataggio solamente sul working tree ad un salvataggop permanente con un indice di tutti gli snapshot su git.
